# Agent Skills 管理指示

このディレクトリは、Claude Code、Codex などで共有する Agent Skills の管理場所である。ここには Skills の構成と、このディレクトリ固有の注意点だけを記載する。個人の常時指示やリポジトリ全体の作業ルールは、ルートの `AGENTS.md` または各クライアントの指示ファイルを正本とする。

## 構成

- 各スキルは `skills/<skill-name>/` に置き、入口を `SKILL.md` とする。パッケージ由来などのシンボリックリンクも許可するが、解決先に `SKILL.md` が存在することを確認する。
- ディレクトリ名と `SKILL.md` の frontmatter にある `name` を一致させる。
- `SKILL.md` の frontmatter には `name` と `description` を置き、`description` に用途と発動条件を簡潔に書く。発動条件を別の重複した一覧で管理しない。
- スキル固有の資料、スクリプト、テンプレート、アセットは、そのスキルのディレクトリ内にまとめ、`SKILL.md` から相対パスで参照する。

## 変更方針

- 変更前に対象の `SKILL.md` と参照先を読み、既存の構成と実際の挙動を確認する。
- `SKILL.md` の説明、手順、スクリプトの実装が同じ動作を指すように保つ。
- 既存の資料やアセットを再利用し、長いチュートリアルやコードから推測できる説明をここへ追加しない。
- このファイル自体を短く保ち、特定スキルの詳しい知識や再利用手順は各スキルの `SKILL.md` などに置く。
- 認証情報や秘密値をスキルへ埋め込まない。必要な環境要件や個人環境への依存は、スキルの説明に明記する。
- 毎回の実行を保証する必要がある処理は、文章上の「必ず」だけに頼らず、適切な hook や設定で担保する。

## 所有境界

- `~/.agents/skills` には外部インストールされたスキルも共存するため、Home Manager では管理対象のスキルだけを個別にリンクする。ディレクトリ全体を置き換えない。
- パッケージ由来のシンボリックリンクなど、Home Manager の activation が生成するものは直接編集・コミットせず、生成元や設定を変更する。

## 検証

- frontmatter の `name` と `description`、参照パス、コマンド例が実際の構成と一致することを確認する。
- シンボリックリンクを含むすべてのスキルで `SKILL.md` に到達でき、`name` とディレクトリ名が一致することを確認する。
- 変更に関係するスクリプトやチェックを実行し、実行結果を確認してから完了とする。
